## 📌 Project Overview

This project uses **IBM SPSS Modeler** to predict the winner of IPL (Indian Premier League) cricket matches based on historical match data and team performance patterns. The goal is to apply predictive analytics techniques to a real-world sports dataset and generate accurate, data-driven predictions.

---

## 🎯 Objectives

- Analyze historical IPL match data to identify key winning factors
- Build a classification model to predict match outcomes
- Evaluate model accuracy and optimize performance
- Present insights through a structured data science workflow

## 📊 Methodology

```
Data Collection → Data Cleaning → Exploratory Analysis → Feature Selection → Model Building → Evaluation → Prediction
```

1. **Data Collection** — Sourced historical IPL match data including team stats, venue, toss results, and player performance
2. **Data Preprocessing** — Handled missing values, encoded categorical variables, normalized features
3. **Exploratory Data Analysis** — Identified patterns in toss decisions, home advantage, and team win rates
4. **Model Building** — Applied classification algorithms in IBM SPSS Modeler
5. **Evaluation** — Assessed model using accuracy metrics and confusion matrix
6. **Prediction** — Generated match winner predictions with confidence scores
